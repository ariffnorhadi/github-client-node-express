# GitHub API Client

A Node.js web application that demonstrates software architecture principles by consuming GitHub's API to display user profile information, repository listings, and issues.

## Project Overview

This project was created as part of a software architecture learning journey, starting from the [Express.js Hello World example](https://expressjs.com/en/starter/hello-world.html). It demonstrates:

- REST API consumption
- Environment configuration
- MVC-like architecture
- Frontend-backend integration

## Features

- GitHub Profile Information Display
- Repository Listing
- Issues Tracking
- Environment-based Configuration (generated from express generator)
